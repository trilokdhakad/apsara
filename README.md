# Apsara

> The intelligence layer for college admissions.

Apsara is exploring a data-driven approach to admissions decision-making.

Instead of treating admissions as a static search or prediction problem, the long-term product aims to turn a student's profile, preferences, constraints, and changing admissions data into an evolving strategy.

## Current prototype

The current MVP is a product landing page and interactive proof-of-concept.

It demonstrates the concept through:

- a real anonymized Indian medical counselling case
- round-by-round strategy evolution
- structured admissions data
- an illustrative international admissions example
- the broader product vision

The current prototype does not yet implement the full admissions intelligence engine.
